# Good Practices for Software Development

------------------------------------------------------------------------

### Question 1

Which point(s) were new to you?

Batching questions into one message was new to me. I usually send doubts
one by one. Now I understand sending everything in one clear message
saves time and makes it easy for others to reply.

------------------------------------------------------------------------

### Question 2

Which area do you think you need to improve on? What are your ideas to
make progress in that area?

🔸 I need to improve in over-communicating. Sometimes I wait too long to
inform about delays or blockers.

🔹 I will inform early if I see any delay.

🔸 I will give small regular updates about my work.

🔹 I will use group chat more instead of private messages.
